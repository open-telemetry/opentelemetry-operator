# Changelog — Apache HTTPD / Nginx auto-instrumentation image

All notable changes to the OpenTelemetry Apache HTTPD auto-instrumentation image
(`ghcr.io/open-telemetry/opentelemetry-operator/autoinstrumentation-apache-httpd`)
are recorded here, one entry per published `<sdk-version>-<revision>` image tag.
The Nginx auto-instrumentation shares this image, so its changes are recorded here
too. See [../README.md](../README.md) for the tagging scheme.

Entries are added automatically by the autoinstrumentation-revision tooling when
the image's SDK version or contents change; see [../README.md](../README.md).
